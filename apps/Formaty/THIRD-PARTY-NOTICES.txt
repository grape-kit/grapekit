Formaty — Üçüncü taraf bileşenler / Third-party components
=========================================================

Formaty'nin kendi kaynak kodu MIT lisanslıdır: https://github.com/grape-kit/grapekit
Formaty's own source code is MIT licensed: https://github.com/grape-kit/grapekit

Formaty aşağıdaki açık kaynak bileşenleri kullanır. Bu bileşenler değiştirilmeden, ayrı dosyalar
(DLL/EXE) olarak dağıtılır; LGPL lisanslı kütüphaneleri aynı arayüze sahip kendi derlemelerinizle
değiştirebilirsiniz. Kaynak kodlarına aşağıdaki adreslerden ulaşabilirsiniz.

Formaty uses the following open-source components. They are distributed unmodified as separate
files (DLL/EXE); you may replace the LGPL-licensed libraries with your own builds that expose the
same interface. Their source code is available at the addresses below.
